# 🏨 DORMORA - A Smart Hostel Management Tool

[![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python&logoColor=white)](https://www.python.org/)  

**DORMORA** is a **smart analysis and prediction system** designed to improve everyday hostel living.  
It helps students and hostel wardens **understand daily patterns, predict peak hours, and make informed decisions**, all through **simple, meaningful insights**.  

All data is stored as **CSV files** inside the `data` folder.


# ✨ Features of DORMORA

- 💧 Report water & washroom issues  
- 👥 Roommate preference entry + basic matching  
- 📝 Submit and view complaints (with date & time)  
- 🍽️ Add & view mess menu and attendance  
- 📊 Dish popularity check  
- ⚡ Simple smart alerts (water usage, high skip count)  


# 🛠 Tech Used

- Python 🐍  
- CSV files for data storage  
- Basic file handling

# 🚀 How to Run the Project

1. **Install Python 3.10+**  
2. **Open the folder in VS Code**  
3. Run the command:

```bash
python main.py
```
